# BARVA Player Content Pack

This pack contains:

1. A standard player-facing game manual.
2. A separate tips and hints guide.
3. A 60–75 second cinematic hype trailer script.
4. A 90–120 second explanatory game-description script, plus a short store description.

The public-facing name has been standardised as **BARVA**. Internal names such as “Java Bar Sim v3” and “JavaBarGUI” have been removed from the player copy.
