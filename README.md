# BARVA V0.1

Portable Windows build of **BARVA**.

## Run

Open:

`BARVA/BARVA.exe`

No separate Java install should be needed. The bundled runtime is included inside the `BARVA/runtime` folder.

## Included

- `BARVA/` - the packaged game app
- `BARVA_Player_Content_Pack/` - player guide, tips and video/store copy

## Version

Frozen release: **V0.1**
