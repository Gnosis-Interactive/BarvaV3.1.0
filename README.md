# BARVA

BARVA is a Windows pub-management simulation from Gnosis Interactive.

## Download

Download the latest portable Windows build from:

**[BARVA v3.1.0 releases](https://github.com/Gnosis-Interactive/BarvaV0.1/releases/latest)**

Choose `BARVA-3.1.0-windows-portable.zip`, extract the complete `BARVA`
folder, and open `BARVA.exe`. A separate Java installation is not required.
Do not run the executable from inside the ZIP.

The `.sha256` file on the release page can be used to verify download
integrity.

## About BARVA

Run a neighborhood pub night after night while balancing:

- staff, stock, service, and security;
- cash flow, supplier relationships, and regulatory pressure;
- reputation, regulars, rivals, upgrades, milestones, and prestige.

Your choices persist, interact, and shape the identity of your pub.
