# BARVA v3.1.0

BARVA is a Windows pub-management simulation from Gnosis Interactive.

## Download

Download `BARVA-3.1.0-windows-portable.zip`, extract the complete `BARVA`
folder, and open `BARVA.exe`. A separate Java installation is not required.

Do not run the executable from inside the ZIP.

## In this release

- Manage the nightly operation and long-term development of your own pub.
- Balance staff, stock, service, security, finances, reputation, and upgrades.
- Build a distinct pub identity through persistent choices and progression.
- Save and continue your campaign between sessions.
- Use the included player guide and driver-mechanics reference when needed.

## Windows notice

BARVA may initially trigger a Microsoft Defender SmartScreen reputation
warning while the release is new. Only download BARVA from the official
Gnosis Interactive GitHub or itch.io pages.
